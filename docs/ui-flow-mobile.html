Mobile UI — screen flow

"Reel commerce" at mobile width (<lg breakpoint): a full-screen product feed (swipe up/down) that swipes right into an Instagram-profile-style Wall, plus a 5-tab bottom bar (Feed · Wall · Search · Bag · Me) replacing the hamburger menu and header icons. Transactional screens (cart, checkout, account, legal) keep the same single-column forms as the web flow, just with mobile chrome around them. Reflects the actual app/(shop) / app/(auth) layout and components/shop/mobile/.
